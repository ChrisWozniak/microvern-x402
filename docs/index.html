MicroVern is a paid API that explains unsigned Algorand transaction groups, highlights risky actions, and evaluates your policy before a wallet signs anything.

View sourceExplore the API

Readable actions

Transfers, opt-ins, app calls, rekeys, close-outs, and asset administration become clear, structured findings.

Policy-aware

Set limits for ALGO and USDC movement, rekeys, close-outs, and known application IDs.

HTTP-native payment

The inspection endpoint uses x402 v2 with Algorand USDC. No API key, account custody, or wallet secret is required.

One focused endpoint

POST /v1/inspect-transaction
Content-Type: application/json
Idempotency-Key: <8–128 URL-safe characters>

{
  "network": "algorand-mainnet",
  "unsignedTransactionGroup": "<base64 unsigned Algorand transaction group>",
  "policy": { "maxAlgoSend": 10, "allowRekey": false }
}

The first request receives an x402 402 Payment Required response. A capable client settles the quoted USDC payment and retries to receive the deterministic report.

Built for cautious review

MicroVern does not custody funds, accept wallet secrets, submit customer transactions, or claim to guarantee safety. It is deterministic decision support; people should still verify transaction details before signing.

Testnet flow verified end-to-end: an unpaid request returned Testnet USDC requirements and a paid retry returned an inspection report. View the Testnet settlement.

MainNet readiness

Before MainNet is enabled, MicroVern requires a dedicated receiver, durable shared PostgreSQL idempotency storage, an always-on deployment, public metadata, and a deliberately approved small payment check.
