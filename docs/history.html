Private browser audit trail

Remember what was reviewed.

Keep completed MicroVern reports in this browser under their stable report ID. The original unsigned transaction group is never saved here.

Save a completed report

Paste a report to retain a private, local copy. Use the Review console’s “Save private audit copy” button for the quickest route.

What stays private

History stays only in this browser. It is stored in browser local storage and is never sent to MicroVern, Render, GitHub Pages, or a wallet.

Saved records contain a sanitized report, its request-hash report ID, save time, and an optional payment transaction ID. They never include the original unsigned request.

Browser data clearing removes this history. It does not sync across devices or serve as a substitute for your own records.

Saved reports

Open a stored report in the readable review screen, download it, or remove it from this browser.

MicroVern never saves the unsigned transaction group in this private browser history. A report is decision support, not authorization to sign.
