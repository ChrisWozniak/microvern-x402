Local evidence verification

Verify what was reviewed.

Check that a completed MicroVern report is intact and bound to the exact unsigned request you hold. This runs entirely in your browser; nothing you paste is sent anywhere.

Verify report evidence

Provide both the completed report and the original request. The report must contain its request hash and report checksum.

What this proves

Integrity and binding, not approval. This recomputes the report checksum and the request hash from the data you provide.

It does not prove the counterparty is trustworthy, that off-chain terms are fulfilled, or that you should sign.

MicroVern reports are not wallet-signed attestations. A successful result means the report is internally intact and bound to this exact original request.

MicroVern never signs, broadcasts, or stores transactions on this page.
