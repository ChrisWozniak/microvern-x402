What is shared?

The URL fragment stays in the browser. MicroVern’s server and GitHub Pages do not receive the part after #.

By default, the link contains the report and any payment transaction ID you provide. It does not include the original unsigned transaction group.

Choose “Include the original request” only when a recipient needs local cryptographic binding verification. Treat the resulting link as private.

MicroVern never signs or broadcasts customer transactions. A report is decision support, not a guarantee of safety or financial advice.
